# Play & Learn with Bip — `bipthebot.net`

Official static website, color-matched interactive learning game, episode theater, and printable coloring book pack for **Play & Learn with Bip** (`@playlearnwithbip`).

## Quick Setup (2 Steps)
1. **Optional — Add Your Exact YouTube "Gigi" Voice:** Open `1-Gigi-Voice-Generator/gigi-voice-studio.html` in Chrome, paste your ElevenLabs API key, click Generate, and move the unzipped `.mp3` files + `manifest.json` into `2-Upload-Inside-Here-To-GitHub/audio/`.
2. **Upload to GitHub Pages:** Upload all files inside `2-Upload-Inside-Here-To-GitHub/` (`index.html`, `styles.css`, `game.js`, `CNAME`, `.nojekyll`, `assets/`, `audio/`) directly to the root of your GitHub repository.
